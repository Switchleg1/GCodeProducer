# Default start and end templates

These are generic examples, not machine-qualified posts. Reset replaces a box with
its workflow's default; blank/whitespace-only boxes also use the default.
For FDM, the emitter additionally sets extrusion mode and resets E; requested
acceleration is emitted separately. See [templates](../gcode-templates.md).

## fdm start

```gcode
; {machine} - {material} ({material_type}), {nozzle} nozzle, {layer_height} mm layers
G21 ; millimetres
G90 ; absolute positioning
{if chamber_temp > 0}M141 S{chamber_temp} ; set chamber
{endif}M140 S{bed_temp_first} ; set bed
M104 S{nozzle_temp_first} T{tool} ; set nozzle
M190 S{bed_temp_first} ; wait for bed
{if chamber_temp > 0 and wait_for_chamber}M191 S{chamber_temp} ; wait for chamber
{endif}M109 S{nozzle_temp_first} T{tool} ; wait for nozzle
G28 ; home all axes
```

## fdm end

```gcode
M104 S0 T{tool} ; nozzle off
M140 S0 ; bed off
{if chamber_temp > 0}M141 S0 ; chamber off
{endif}M107 ; fan off
G91 ; relative
G1 Z10 F600 ; lift
G90 ; absolute
M84 ; motors off
```

## cam start

```gcode
; {machine} - {tool_name} (T{tool}, {tool_diameter} mm)
G21 ; millimetres
G90 ; absolute positioning
G0 Z{safe_z} ; safe height
T{tool} M6 ; tool change
M3 S{spindle_rpm} ; spindle on
```

## cam end

```gcode
G0 Z{safe_z} ; safe height
M5 ; spindle off
G0 X0 Y0 ; park
M30 ; end of program
```
